## 확인 수준 표기

조사 결과에는 아래 표기를 붙인다. 논문에 인용하기 전에는 [보도 확인]과 [초록 확인] 항목을 원문으로 다시 확인해야 한다.

- **[원문 확인]**: 1차 자료(통계표, 공식 보도자료, 논문 본문, 기업 공시)를 직접 열어 확인했다.
- **[보도 확인]**: 1차 자료를 인용한 기사로 확인했다. 1차 자료 자체는 아직 보지 못했다.
- **[2차 자료]**: 법무법인 블로그처럼 1차 자료도 언론 보도도 아닌 자료로 확인했다.
- **[초록 확인]**: 논문의 서지 정보와 초록만 확인했다.
- **[미확인]**: 검색 요약이나 추론에만 근거한다. 인용하지 않는다.
